# Feature Requests & Roadmap

Last updated: 2026-10-01 | Owner: Product Management

## How Requests Are Handled

- Every feature request received through support is tagged and logged in the product board with the customer's account ID.
- Requests are reviewed **quarterly**; the next roadmap review closes October 31, 2026.
- We do not commit to delivery dates outside this document. If a customer demands a date, quote only what appears below.

## Keyboard Shortcuts

The web editor already supports keyboard shortcuts; the list lives in-app under **Help → Keyboard shortcuts**. Highlights: `Cmd/Ctrl+K` command palette, `Cmd/Ctrl+Shift+E` export, `Cmd/Ctrl+/` toggle shortcut help. Customers asking for shortcuts should be pointed to this list — they exist today.

## SSO and Enterprise Feature Requests

SAML SSO, SCIM, and custom data residency are Enterprise features sold through Customer Success. Threats to cancel over SSO (or any Enterprise-gated feature) must be escalated to the retention queue — never quote pricing or timelines from support.

## Saying No Gracefully

Acknowledge the request, state where it sits (logged / under evaluation / committed with target), and confirm the customer's account ID is attached so they hear back if status changes. Log tag `roadmap-inquiry` on every reply.
